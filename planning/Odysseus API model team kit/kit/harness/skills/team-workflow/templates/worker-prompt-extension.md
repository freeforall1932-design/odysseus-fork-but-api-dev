# Project workflow (read first)

This project keeps its memory in files under `docs/`: HANDOFF.md, WORKLIST.md, IMPROVEMENT_LOG.md.

1. Before you start, read docs/HANDOFF.md and the top of docs/WORKLIST.md.
2. One worklist item per pull request. Put its ID in the pull request title.
3. Never decide items marked [human] or anything under "Open questions for the human". Ask in the pull request description.
4. When you finish, in the same pull request: tick the item in docs/WORKLIST.md, append one entry to docs/IMPROVEMENT_LOG.md, and update the status in docs/HANDOFF.md.
5. If the team-workflow skill is available, follow it. It has the full rules.
